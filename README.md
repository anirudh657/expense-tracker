# 💰 Expense Tracker CLI

A simple Command Line Expense Tracker built using **Python**. This project helps users manage their daily expenses by adding, viewing, searching, deleting, and generating monthly reports.

---

## 🚀 Features

- ➕ Add Expenses
- 📋 View All Expenses
- 🔍 Search Expenses by Category
- 🗑️ Delete Expenses
- 💵 Calculate Total Expenses
- 📅 Generate Monthly Reports

## 📖 How It Works

### 1. Add Expense
Stores an expense with:
- Date
- Category
- Amount
- Note

### 2. View Expenses
Displays all saved expenses with their details.

### 3. Search Expense
Find expenses based on their category.

### 4. Delete Expense
Delete an expense using its expense number.

### 5. Total Expense
Calculates the total amount spent across all expenses.

### 6. Monthly Report
Displays all expenses for a selected month and calculates the total spending for that month.
